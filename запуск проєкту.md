GearCraft | Запуск проєкту на іншому комп'ютері

1. Встановити Node.js

1 Перейти на офіційний сайт Node.js: https://nodejs.org/en/download
2 Завантажити версію LTS для Windows.
3 Запустити інсталятор і залишити стандартні налаштування.
4 Після встановлення відкрити новий термінал PowerShell або CMD і перевірити:

node -v
npm -v

Якщо обидві команди показують версії, Node.js встановлено правильно.

2. У проєкті мають бути папки: client та server
3. Налаштувати сервер

Відкрити термінал powershell у папці проєкту і виконати команди:

cd server
npm install
copy .env.example .env

4. Після цього відкрити файл `server/.env` і змінити дані на свої:

Для роботи проєкту потрібна база даних PostgreSQL. Треба створити базу даних, використати середовище або гілку з назвою production, і туди експортувати 6 таблиць з папки production проєкту, і вказати підключення до неї у змінній `DATABASE_URL`.

Для роботи завантаження зображень потрібно налаштувати Cloudinary. Для цього треба створити акаунт на сайті Cloudinary, взяти дані `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` і вписати їх у файл `server/.env`.

Для роботи надсилання листів потрібно налаштувати SMTP. Якщо використовується Gmail, потрібно вказати `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`, свою пошту в `SMTP_USER`, пароль додатку Google у `SMTP_PASS`, а також адресу відправника в `MAIL_FROM`.

5. Налаштувати клієнт. Відкрити другий термінал у папці проєкту і виконати команди:

cd client
npm install
copy .env.example .env

У файлі `client/.env` має бути:

VITE_API_URL=http://localhost:5000/api

6. Команди щоб запускати проєкт
   Відкрити перший термінал PowerShell сервер:

cd server
npm run dev

За замовчуванням сервер працює за адресою: http://localhost:5000

Відкрити другий термінал PowerShell клієнт:

cd client
npm run dev

Після запуску відкрити адресу, яку покаже Vite, зазвичай: http://localhost:5173
